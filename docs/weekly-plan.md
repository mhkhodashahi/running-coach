# Planning and Approval

Weekly suggestions are pending proposals, not automatic plan changes. The
planner uses fixed commitments, protected habits, active memory rules, recent
training, the active goal and the shared weekly load reference.

Fixed and protected sessions remain unchanged. Flexible sessions obey the hard-day
spacing, long-run progression and weekly load checks. Each change carries a
reason, supporting facts and any structured workout. Unknown load is not zero.

Apply validates the exact selected set before writing. Dependency groups are
all-or-nothing. A changed plan version makes the old proposal stale. An accepted
proposal stores before/after snapshots for undo; logged activities are not changed.
Workout details are copied into the approved session. Moving a session creates
a new proposal. Scheduled jobs create suggestions but never approve them.

See [metrics](metrics.md) for the shared reference and [architecture](architecture.md)
for transaction ownership.
